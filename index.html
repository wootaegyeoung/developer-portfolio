3. 핵심 기술 이슈 및 문제 해결

CASE 01. 대용량 시계열 데이터의 특정 시점 상태 복원

[Problem] 훈련 Replay 데이터는 시간의 흐름에 따라 객체 상태가 누적 변경되는 구조로, 특정 시점으로 이동 시 처음부터 모든 이벤트를 순차 적용하면 데이터 증가에 따라 처리 지연이 심화되는 문제가 발생했습니다.

[Analysis] 매번 전체 이벤트를 재처리하는 대신, '가장 가까운 기준 상태(Keyframe) + 이후 발생한 변경사항(Delta Event)' 조합으로 상태를 복원하도록 구조 개선을 결정했습니다.

Replay Dataset ├── Manifest & Plan / Metadata └── Event Stream ├── Keyframe (기준 상태) ├── Delta Event 1 → Delta Event 2 ... └── Keyframe (구간별 기준)

[Solution & Result] 일정 간격의 Keyframe 및 Indexing 구조를 설계하여 탐색 구간을 최적화했습니다. 전체 데이터 순차 처리 대비 목표 시점 상태 복원 성능 및 메모리 효율을 극대화했습니다.

CASE 02. 일반 GIS 객체와 전술부호의 서로 다른 Rendering Pipeline 통합

[Problem] WPF Vector로 표현되는 일반 GIS 객체와 C++ Native 모듈에서 이미지를 생성하는 전술부호가 단일 Overlay 문서 내에서 혼재되어 파이프라인 관리가 복잡해지는 문제가 있었습니다.

[Analysis] 공통 Overlay Data 구조를 유지하면서 객체 유형에 따라 Rendering 책임을 명확히 분리하는 패턴을 설계했습니다.

Overlay Object ──┬── 일반객체 ──> WPF Vector Rendering └── 전술부호 ──> C++ COM ──> Native Symbol Renderer ──> Image Rendering

[Solution & Result] 직렬화 시 전술부호의 부호 코드, 채움, 수식자, 투명도 등의 옵션 손실을 방지하도록 인코딩 구조를 정립하고 Managed C#과 Native C++/COM 연동을 안정화했습니다.

CASE 03. 다양한 실행환경과 Native Dependency를 포함한 배포 구조 정리

[Problem] .NET Desktop Runtime, C++ Native Runtime, COM Module, 지도 엔진 DLL 등 복잡한 의존성으로 인해 운영 환경 배포 시 누락 오류 발생 가능성이 존재했습니다.

[Solution & Result] Build → Dependency 구성 → COM 등록 → Installer 생성으로 이어지는 자동화 절차를 정립하여 환경별 설치 오류율을 크게 낮추고 검증된 x64 패키지를 구성했습니다.

4. 핵심 기술 이슈 및 문제 해결

CASE 01. Custom Interceptor 중심 인증구조를 Spring Security로 통합

[Problem] 로직별로 분산되어 있던 Custom Interceptor의 인증/인가 접근 제어를 개선하고 통합 관리가 필요했습니다.

[Solution] OAuth2 Login과 Spring Security Filter Chain을 결합하여 공통 보안 계층으로 통합하고, 미승인 사용자를 고려한 Role 기반 접근 제어 정책을 도입했습니다.

CASE 02. MySQL에서 PostgreSQL로의 DB Migration & PK 전략 대응

[Problem] MySQL 종속적인 PK 생성 방식 및 Type 차이로 인해 simple DB 전환 시 JPA Entity 매핑 오류가 발생했습니다.

[Solution] JPA @SequenceGenerator와 PostgreSQL Sequence 간 명확한 생성 전략을 정립하고 데이터 이관 시의 무결성을 확보했습니다.

CASE 03. Secure Cloud Migration (Cloud Run + Secret Manager)

[Problem] 설정 파일 내 노출 위험이 있던 DB Credential 및 OAuth Secret의 보안 강화가 요구되었습니다.

[Solution] GCP Secret Manager에 비밀 정보를 격리 관리하고 Cloud Run 컨테이너 실행 시 환경 변수로 주입하는 구조를 구축하여 보안 표준을 준수했습니다.
