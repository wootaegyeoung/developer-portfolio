PROJECT 01 · 2025.12 ~ 2026.07

국방 훈련통제 GIS 솔루션 개발

훈련통제 과정의 부대·임무·위치 정보를 GIS 지도 위에 표현하고, 일반 공간객체와 국방 표준 전술부호(MilSymbol)의 편집·표현, Replay, 외부 훈련통제 시스템 연동을 제공하는 Windows 기반 GIS 애플리케이션을 개발했습니다.

프로젝트 정보

수행 기간2025.12 ~ 2026.07
담당 역할GIS Application · MilSymbol 전술부호 · Replay · ASTERIX CAT062 데이터 처리 · 외부 시스템/CesiumJS/Android 연동 · 배포 구성
기술C#, .NET 8, WPF, MVVM, C++, ATL/COM, XML, JSON/NDJSON, PostGIS, CesiumJS, Android, MariaDB

아키텍처와 담당 영역

External Training Control System │ API / coordinate request ▼ GIS Application (.NET 8 / WPF / MVVM) ├─ GIS Object & Overlay Processing ├─ Replay Processing (Keyframe + Delta Event) └─ External Integration ├─ GIS Map Engine / Spatial Data └─ C++ ATL/COM MilSymbol Renderer
  • GIS Application: 지도 이동·확대·회전·좌표변환, UI 상태관리, 외부·DB 데이터와 지도 객체 상태 동기화
  • Spatial & MilSymbol: XML Overlay Load/Edit/Save, 일반 객체·전술부호 Rendering Pipeline 분리, 부호 옵션 직렬화와 복원
  • Replay Engine: JSON/NDJSON 시계열 이벤트, Keyframe·Delta Event 기반 상태 복원, 재생·일시정지·배속
  • Deployment: .NET/Native Runtime, 지도 엔진 DLL, COM Module 등록, x64 Installer 패키지 검증

핵심 문제 해결 및 성과

CASE 01. 대용량 시계열 데이터의 특정 시점 상태 복원

전체 이벤트를 처음부터 적용하는 방식 대신 가장 가까운 Keyframe + 이후 Delta Event만 적용하도록 설계했습니다.

Impact · 내부 성능 검증 기준, 특정 시점 탐색 시간 약 85% 단축 · 메모리 점유율 약 60% 절감

CASE 02. 일반 GIS 객체와 전술부호 Rendering Pipeline 통합

Managed C#과 Native C++/COM 간 Rendering Contract를 안정화해 MilSymbol과 일반 GIS 객체를 단일 Overlay 문서에서 일관되게 처리했습니다.

CASE 03. Native Dependency를 포함한 배포 표준화

Build → Dependency 구성 → COM 등록 → Installer 생성 절차를 정립했습니다.

Impact · 검증 대상 운영 환경에서 의존성 누락 배포 오류율 0% · 반복 수동 점검 제거로 배포 준비 리드타임 단축
