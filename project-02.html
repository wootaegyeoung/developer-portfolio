PROJECT 02 · 2025.06 ~ 2025.07

라이선스 관리 시스템 현대화 및 GCP 전환

온프레미스 레거시 라이선스 발급·배포 시스템을 Java 21과 Spring Boot 3로 현대화하고, OAuth2 인증과 GCP Cloud Run 기반 관리형 환경으로 마이그레이션했습니다. 인증·DB·배포를 함께 개선해 운용 효율성과 보안성을 높였습니다.

핵심 문제 해결 및 성과

CASE 01. Custom Interceptor 중심 인증구조 통합

OAuth2 Login과 Spring Security Filter Chain을 결합해 분산된 접근 제어를 공통 보안 계층으로 통합하고 Role 기반 정책을 도입했습니다.

CASE 02. MySQL → PostgreSQL DB Migration

JPA @SequenceGenerator와 PostgreSQL Sequence의 생성 전략을 정립해 PK·타입 차이에 따른 매핑 오류를 해소하고 이관 무결성을 확보했습니다.

CASE 03. Secure Cloud Migration

Secret Manager에 DB Credential·OAuth Secret을 격리하고 Cloud Run 실행 시 환경 변수로 주입했습니다. Cloud Build·Docker 배포 절차를 표준화해 수동 설정을 줄였습니다.
